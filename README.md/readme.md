# AI Gesture Mouse

AI Gesture Mouse is an AI-powered touchless mouse system
that allows users to control the computer using hand gestures
captured through a computer webcam.

## Problem

Traditional mouse interaction requires physical contact.
This project explores a touchless alternative using computer vision.

## Proposed Solution

The system uses a webcam to detect hand gestures and converts
those gestures into mouse actions.

## Technologies

- Python
- OpenCV
- MediaPipe
- PyAutoGUI

## Project Status

Currently in the planning and development stage.
